# JCE Tree Service — Website Project

- `content/` — brand assets and the approved briefs (Creative Brief, Brand Brief, logo files)
  this build is based on.
- `wp-content/themes/jce-tree-service/` — the custom WordPress theme. See its
  [README](wp-content/themes/jce-tree-service/README.md) for structure and setup steps.
- `tools/` — static checks for the theme, runnable without a WordPress install:
  `./tools/check-all.sh`. See [tools/README.md](tools/README.md).

Content (Pages, Services, Locations, Testimonials, blog posts, Landing Pages) is meant to be
authored and edited through WordPress admin; the PHP theme is built and version-controlled
here.
